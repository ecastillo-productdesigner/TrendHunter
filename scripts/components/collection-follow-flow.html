Follow a collection

Collection detail pages use the existing Follow button. Following changes it to Following with the primary lime fill, confirms the collection name in the existing five-second toast, and offers View Collections linking to the feed’s Collections tab. Clicking Following unfollows and confirms the change. Long collection names wrap inside the toast, which stays above the prototype settings button so its link and close control remain tappable. Follows persist in this prototype browser across pages and reloads, and appear in both feed and personal-profile Collections. No account service or live analytics is connected.

Inline collection interest summary

Every collection detail page places a two-line summary below the description: the signed percentage and shared chevrons on the first line, then one grouped metadata phrase, such as Updated 3hrs ago · Interest · 7 days, on the second line. The collection name has no chevrons. Follow / Following and the outlined Share action sit together on the right when space allows and wrap below on narrow screens. The percentage uses --type-card-headline (28px / 28px, weight 800) and --color-interest-rising or --color-interest-falling. Metadata uses --type-helper and --color-text-dim, with a middle dot separating Updated recency from Interest · 7 days. Percentage to chevrons uses --spacing-layout-md (16px); the two summary lines use --spacing-component-xs (4px). Summary to actions and Follow to Share use --spacing-layout-lg (24px), with --spacing-layout-md (16px) between wrapped action rows. There is no extra frame. The shared catalog provides each collection’s illustrative percentage and update hours, matching What’s Changing. The selected sample fluctuations update the visible percentage and chevrons together. Follow persistence, toast feedback and native sharing keep their existing behavior.
