New feature announcement · Following

A dismissible announcement sits at the top of For You / Discover, before the prediction-result banner and first story. It is hidden in other feed tabs. Underlined Try it opens Following with an unselected starter view, even when the browser already has saved follows. Signed-out visitors sign in first and return to that view. The simulation preserves all existing follows. Follow buttons add the selected collection or person to actual browser-local follows and retain the suggestions so several can be chosen. See Following opens the real people activity feed; if only collections were picked, View Collections opens that feed. Leaving the tab ends the simulation. Genuine first-time readers also see the same three suggestion groups when they follow no people. Dismissal is remembered in this browser for this feature version. Prototype settings → Show new feature restores it and returns to the top of the feed, including when opened from another page.

Uses --feature-announcement-bg (#34D399) and --feature-announcement-text (#0F0F0F) in both themes, --type-body with --type-weight-bold for the introduction, --radius-md (10px), --spacing-component-ms (12px) padding/gaps, and --spacing-layout-lg (24px) after the banner. The celebration emoji is decorative at --icon-size-xl (32px). Close sits at the top right, inset by --spacing-component-xs (4px), and uses the existing 20px mask inside a --icon-size-2xl (48px) target. The text area ends exactly --spacing-component-ms (12px) before the visible X. Its right inset accounts for the 4px edge inset and the 20px icon centered inside the 48px target. Phone gaps use --spacing-component-sm (8px). Only the close icon changes on hover, from near-black to --color-icon-on-media (#D1D5DB), with no background change. Try it is near-black and underlined, dims to --color-icon-on-media on hover, and has a near-black keyboard focus ring. The close control retains its near-black keyboard focus ring. Dismissal puffs outward to 1.06 scale with a 4px blur and fade over --motion-feature-dismiss (300ms), then removes the banner. The scale and blur use --motion-feature-dismiss-scale and --motion-feature-dismiss-blur. Reduced motion skips the puff. Restoring during dismissal cancels it. All visual values use DS tokens. Preview controls below are isolated from account state.
