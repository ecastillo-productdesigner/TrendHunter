New feature announcement · Following

A dismissible announcement sits at the top of For You / Discover, before the prediction-result banner and first story. It is hidden in other feed tabs. It contains no CTA or navigation link. Dismissal is remembered in this browser for this feature version. Prototype settings → Show new feature restores it and returns to the top of the feed, including when opened from another page.

Uses --color-background-callout (purple) and --color-text-on-media (white) in both themes, --type-body with --type-weight-bold for the introduction, --radius-md (10px), --spacing-component-ms (12px) padding/gaps, and --spacing-layout-lg (24px) after the banner. The celebration emoji is decorative at --icon-size-xl (32px). Close sits at the top right, inset by --spacing-component-xs (4px), and uses the existing 20px mask inside a --icon-size-2xl (48px) target. The content reserves that target plus the 4px inset and 12px padding so copy never overlaps it. Phone gaps use --spacing-component-sm (8px). Only the close icon changes on hover, from white to --color-icon-on-media (#D1D5DB), with no background change. The close control retains its white keyboard focus ring. Dismissal puffs outward to 1.06 scale with a 4px blur and fade over --motion-feature-dismiss (300ms), then removes the banner. The scale and blur use --motion-feature-dismiss-scale and --motion-feature-dismiss-blur. Reduced motion skips the puff. Restoring during dismissal cancels it. All visual values use DS tokens. Preview controls below are isolated from account state.
