New feature announcement · Following

A dismissible announcement sits at the top of For You / Discover, before the prediction-result banner and first story. It is hidden in other feed tabs. Underlined Try it opens Following with an unselected starter view, even when the browser already has saved follows. Signed-out visitors sign in first and return to that view. The simulation preserves all existing follows and excludes them from recommendations in every group. It fills each group with up to two unfollowed alternatives from the existing catalog. Follow buttons toggle the selected collection or person in actual browser-local follows and retain the suggestions so several can be chosen. Clicking Following again unfollows and restores Follow. Entering the simulation never clears saved follows; only explicit button clicks change them. See Following opens the real people activity feed; if only collections were picked, View Collections opens that feed. Leaving the tab ends the simulation. Genuine first-time readers also see the same three suggestion groups when they follow no people. Dismissal is remembered in this browser for this feature version. Prototype settings → Show new feature restores it and returns to the top of the feed, including when opened from another page.

The celebration emoji is decorative at --icon-size-xl (32px). The text area ends exactly --spacing-component-ms (12px) before the visible X. Its right inset accounts for the 4px edge inset and the 20px icon centered inside the 48px target. Phone gaps use --spacing-component-sm (8px). Only the close icon changes on hover, from near-black to --color-text-on-media (#FFFFFF), with no background change. Try it is near-black and underlined, turns white with --color-text-on-media on hover, and has a near-black keyboard focus ring. The close control retains its near-black keyboard focus ring. Dismissal puffs outward to 1.06 scale with a 4px blur and fade over --motion-feature-dismiss (300ms), then removes the banner.
