New feature announcement · Following

A dismissible announcement sits at the top of For You / Discover, before the prediction-result banner and first story. It is hidden in other feed tabs. Try it opens Following and focuses its tab for signed-in readers. Signed-out readers go through sign-in and return to Following. Dismissal is remembered in this browser for this feature version. Prototype settings → Show new feature restores it and returns to the top of the feed, including when opened from another page.

Uses --color-background-callout (purple) and --color-text-on-media (white) in both themes, --type-body with --type-weight-bold for the introduction, --radius-md (10px), --spacing-component-ms (12px) padding/gaps, and --spacing-layout-lg (24px) after the banner. The celebration emoji is decorative at --icon-size-xl (32px). Close uses the existing 20px mask inside a --icon-size-2xl (48px) target. Phone gaps use --spacing-component-sm (8px). Try it stays together on one line. The link stays underlined and changes to --buttons-primary-bg-hover on hover. Close uses --color-white-10 on hover; both controls have a white keyboard focus ring. All visual values reuse existing DS tokens. Preview controls below are isolated from account state.
