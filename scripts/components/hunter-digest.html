Hunter Digest

A dated briefing from followed collections appears above the activity feed in Following, with a one-story preview on For You. Both require sign-in and stay hidden during the Following introduction preview. Only actual collection memberships are eligible; shared stories appear once and collections are interleaved before the first five updates are selected. Read your digest opens Following and focuses the briefing. Collection names open their collection; each two-sentence excerpt ends with Read more to its exact article. See all updates expands the remaining summaries. Mark shown updates as caught up acknowledges only the displayed revisions, retaining article-read state and Following notification state. The caught-up and no-collections states provide a link to Collections.

The edition date uses the local calendar date when this page opens. A new date does not manufacture new updates: a caught-up story returns only if its excerpt revision changes. This prototype derives excerpts from the existing sample articles and stores catch-up state in the browser; it has no live publication feed or scheduled delivery. Initial content is labeled as story highlights rather than assigned invented publication times. The preview below is an illustrative edition.

The feed frame uses --radius-x-sm, --stroke-default, --color-border-default and a --stroke-focus accent top border. Padding and section gaps use --spacing-layout-lg; collection-to-story spacing uses --spacing-component-ms; summary spacing uses --spacing-component-sm. The title uses --type-card-headline, story titles --type-section-heading-bold, summaries --type-body, date --type-helper, collection names --type-collection-label and text actions --type-editorial-h4. Semantic theme tokens supply all colors. Actions have a 48px target and visible keyboard focus; no entrance animation is required.
