Hunter Digest

A single dated Hunter Digest card appears on For You for signed-in readers, before the stories. It is absent from Following and hidden during the Following introduction preview. The collapsed card shows its local edition date followed by the actual collection and story update counts on the same metadata line, then one story summary. It has no Today or daily catch-up label. See all updates expands the same card in place using a native keyboard-accessible disclosure; Close digest appears after the last summary and collapses the card without changing tabs. A Feed Complete check-circle icon sits beside it at the end of the card; clicking it hides the daily briefing without marking unopened stories read. It stays hidden for that day’s same update set, and a new story or changed revision can reveal it again. Prototype settings → Show Hunter Digest restores it on For You, including from another page, while preserving individual story catch-up state and the sign-in requirement. Expanded content includes all available summaries without duplicating the preview. A default border divider separates each different collection, including the preview-to-expanded boundary when the next section changes collection. Only actual followed collection memberships are eligible; shared stories appear once and collections are interleaved for the briefing. Collection names open their collection; every two-sentence excerpt ends with Read more to its exact article. Opening an article through its headline or Read more catches up that story’s current revision, removing it from the digest on return or reload. Articles opened elsewhere in the app use the same behavior. Other summaries remain unread, and a changed revision can appear again. No explanatory subheading appears inside the expanded card. The caught-up and no-collections states provide a link to Collections.

The edition date uses the local calendar date when this page opens. A new date does not manufacture new updates: a caught-up story returns only if its excerpt revision changes. This prototype derives excerpts from the existing sample articles and stores catch-up state in the browser; it has no live publication feed or scheduled delivery. Initial content is labeled as story highlights rather than assigned invented publication times. The preview below is an illustrative edition.

The feed frame uses --radius-x-sm, --stroke-default, --color-border-default and a --stroke-focus accent top border. Padding and section gaps use --spacing-layout-lg; collection-to-story spacing uses --spacing-component-ms; summary spacing uses --spacing-component-sm. The title uses --type-card-headline, story titles --type-section-heading-bold, summaries --type-body, date and update counts --type-helper, and collection names --type-section-heading-bold (18px) to match What’s Changing, with --color-text-tertiary and the existing collection momentum chevrons. Text actions use --type-editorial-h4. Semantic theme tokens supply all colors. The Feed Complete icon is 48px with a --color-background-bg-overlay (#343841) fill by default and --hunter-digest-complete-hover (#BEFC4F) on hover or keyboard focus. The specimen disclosure expands, collapses and hides without saving app state. Actions have a 48px target and visible keyboard focus; no entrance animation is required.
