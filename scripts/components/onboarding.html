After the email sign-in Terms and Policies Continue action, the signed-in prototype opens Topics → Collections → Trend Setters → Great Picks. Provider demo sign-in keeps its existing return behavior. Any saved calls and bookmarks remain intact. This exploration uses the existing nine topics, real collection catalogue and fictional creator profiles.

Topics reuse the three-column square topic tiles, their icons and selected color tokens. Collections reuse the pill component in two desktop columns and one phone column, with existing green/red chevrons and a visible selected check. Suggestions respond to topic choices without removing an already selected collection. Trend setters use four distinct 140px author portraits, names and roles, with a focus-colored ring and check when selected.

A fresh flow starts with nothing preselected, even if this browser already has preferences or follows. Existing choices are restored only from a draft the reader made within this onboarding flow. Continue requires at least one selection at each selection step; Skip for now always advances. Progress labels return to visited steps. Draft choices survive Back and reload without changing followed collections or people until See your feed. Great Picks shows the actual choices with edit links, including a useful empty state when every step was skipped. Completion applies chosen topic personalization and adds the chosen Collections/Following entries; skipping never removes existing preferences or follows. Saving errors keep the summary and draft available for retry. The prototype stores these preferences in this browser, not an account backend.

All visual values reuse DS tokens: --type-card-headline, --type-body, --type-helper, --type-editorial-h6, --type-collection-label and --type-button-label; --layout-login-width (376px) for the topic grid and CTA; --layout-answers-page-width (820px) for the wide collection area; --avatar-size-xl (140px); --layout-auth-button-height (50px); existing spacing tokens (4–48px), radii, theme colors and focus strokes. The Skip for now target and its helper note are separated by --spacing-component-ms (12px); Continue retains its 24px gap above that group. The header and footer reuse the existing logo and footer treatments. These references add no new primitive values.
