Prediction results in sidebars

Outside the feed, a desktop sidebar with unread prediction results replaces its voting deck with this centered announcement: Card headline, counted purple sheets, then a full-width primary See results button. The frame uses the shared surface, border and 2px radius, with 24px padding (--spacing-layout-lg) and 28px gaps (layout-lg + component-xs). The primary button uses the active theme’s colors and a 48px minimum height.

Show Prediction Results Card in prototype settings activates three fictional results in place on desktop article, collection and channel pages. See results opens the existing result popup. The unread count and sheet count decrease as results are viewed; after the last unread result, the announcement disappears and the original voting deck returns with its state intact. Reloads, return visits and other tabs use the same unread state. The feed keeps its horizontal banner, and mobile keeps its existing inline voting placement and dedicated results destination. Pages without a desktop prediction sidebar open the feed preview.
