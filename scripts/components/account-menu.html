Account drawer and predictions shortcut

The signed-in profile icon opens the shared Menu drawer component from the right, with Profile and Log Out. Log Out appears only in this account drawer, not in the left Menu drawer. Profile opens the user profile. Log Out ends the sign-in session and returns to the feed. The close icon, Escape key and scrim dismiss the drawer.
