Account drawer and predictions shortcut

The signed-in profile icon opens the shared Menu drawer component from the right, with Your Profile and Log Out separated by the shared full-width DS divider. Log Out appears only in this account drawer, not in the left Menu drawer. Your Profile opens the user profile. Log Out ends the sign-in session and returns to the feed. The close icon, Escape key and scrim dismiss the drawer.

The lightning shortcut appears before the theme control on mobile and tablet, below 960px. It is hidden in desktop navigation. It opens the dedicated Daily Predictions page; the selected icon uses var(--color-border-focus). This page starts with a counted results banner when results exist, followed by the unanswered voting/context deck and saved calls awaiting results. See results opens the same card popup used on desktop; resolved cards are not duplicated inline. Even with unread results, the mobile bolt navigates to this page instead of opening a popup. Skipped predictions stay available; saved votes and resolved predictions are excluded from the unanswered deck. The red dot clears for each result only after its card is viewed, and seen results remain accessible through the page’s banner and the personal profile.
