With no earned badges, a gray First Call medal appears; clicking it expands the short requirement “Vote on your first prediction” and a Start collecting badges link to Daily Predictions. Earned medals show their own collection requirement. The header respects hidden badge choices and refreshes its name and medal whenever the drawer opens. A shared divider separates the header from Log Out, which ends the sign-in session and returns to the feed. The shared close icon, Escape key and scrim dismiss the drawer.

The lightning shortcut appears before the theme control on mobile and tablet, below 960px. It is hidden in desktop navigation. It opens the dedicated Daily Predictions page; the selected icon uses var(--color-border-focus). This page starts with a counted results banner when results exist, followed by the unanswered voting/context deck and saved calls awaiting results. See results opens the same card popup used on desktop; resolved cards are not duplicated inline. Even with unread results, the mobile bolt navigates to this page instead of opening a popup. Skipped predictions stay available; saved votes and resolved predictions are excluded from the unanswered deck. The red dot clears for each result only after its card is viewed, and after the last unread result is viewed, both the banner and dot disappear.
